## 一、问题现象

用户忘记密码，点击「用邮箱验证码登录」提示失败，无法进入账户。

---

## 二、根因（已实测确认）

登录与找回密码都走 **Supabase Auth**，邮件由 Supabase 发送。直接调用接口实测：

| 场景 | 接口 | 实测结果 |
|---|---|---|
| 邮箱验证码登录 | `POST /auth/v1/otp` | **HTTP 500** `unexpected_failure` — Error sending magic link email |
| 找回密码 | `POST /auth/v1/recover` | **HTTP 429** `over_email_send_rate_limit` — email rate limit exceeded |
| 手机号验证码 | `POST /auth/v1/otp` | **HTTP 422** `otp_disabled` — Signups not allowed for otp |

**结论：不是登录逻辑坏了，是邮件发不出去。**

Supabase 默认内置邮件服务限流极严，官方文档写明：

- 默认仅 **2 封/小时**
- 默认服务**不保证送达、无 SLA**
- 配置自定义 SMTP 后初始限流 30 封/小时，可在 Rate Limits 页面上调

项目本身已具备邮件能力（云函数内置 nodemailer，支持 `SMTP_HOST`/`SMTP_USER`/`SMTP_PASS`），但 **`.env` 中未配置任何 SMTP**，未配置时云函数会「自动降级为不发送」。

### 影响面（比预想的大）

| 功能 | 是否受影响 |
|---|---|
| 邮箱验证码登录 | ✗ 受影响 |
| 忘记密码 / 重置密码 | ✗ 受影响 |
| 邮箱注册后验证 | ✗ 受影响（`signUp` 后需邮件验证才能登录） |
| 邮箱 + 密码登录（已注册账号） | ✓ 不受影响 |

## 四、整改方案

### 4.1 邮箱侧（可立即修，强烈建议先做）

**做法**：为 Supabase Auth 配置自定义 SMTP。

- 入口：Supabase Dashboard → Authentication → Emails → SMTP Settings
- 需要：一个可用的 SMTP 服务与凭证（企业邮、QQ 邮箱授权码、Resend、SendGrid、SES 等均可）
- 配完需同步：Authentication → Rate Limits → 调高邮件发送上限

**效果**：邮箱验证码登录、找回密码、注册验证**同时恢复**。

**注意**：Supabase 自身的每小时限流独立于 SMTP 服务商，两边都要调。

### 4.2 手机号侧（本次新增）

**选型**：阿里云 **号码认证服务（PNVS）** 的「短信认证」。

选择理由（与市面方案对比）：

| 方案 | 免资质 | 签名/模板 | 适用性 |
|---|---|---|---|
| **阿里云号码认证（短信认证）** | ✅ 免企业资质 | ✅ 用赠送签名+模板 | **推荐** |
| 阿里云「短信服务」（SMS） | ❌ 需企业认证 | 需自行申请审核 | 不适用 |
| 腾讯云短信 | ❌ 需实名+签名模板审核 | 需自行申请 | 门槛高 |
| Supabase 内置 SMS Provider（Twilio 等） | — | — | 国内送达与合规不适用 |

**关键区别**：要用「**号码认证服务**」，**不是「短信服务」**——后者需要企业认证，前者个人实名即可。

**费用**：按量付费，约 **0.06 元/次**（1 万条以内档位，量大递减）。短信认证**只收发送费**，按运营商回执计费；核验免费。

**接入方式**：
```
前端 supabase.auth.signInWithOtp({ phone })
  → Supabase Auth 生成 OTP
  → Send SMS Hook（HTTP Hook 指向我们的后端）
  → 后端调阿里云 SendSmsVerifyCode，把 OTP 作为模板参数发出
  → 用户输入 → supabase.auth.verifyOtp({ phone, token, type: 'sms' })
```
Supabase 官方支持 `Send SMS Hook`，可用自有短信服务替换内置发送，Hook 返回 200 即视为成功。

## 七、风险与注意

- 短信到达率受运营商管控影响，**务必用赠送签名 + 赠送模板**（两者必须搭配使用）
- 需要加**发送频率限制**（同号 60 秒内一次、单日上限），否则会被刷
- 后端接口需加图形/行为验证，防止短信轰炸
- AccessKey 只放服务端环境变量，**不进仓库**（仓库是公开的）
