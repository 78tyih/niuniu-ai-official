03 · ARCHITECTURE

五层架构，双云函数同源Five layers, dual cloud functions

Frontend
React + Vite + Tailwind（src/），落地页 / 定价 / 账户 / 社区 / 学习中心多页路由
Auth & DB
Supabase：邮箱注册登录、手机号绑定、密码重置；建库脚本 supabase/schema.sql
Server Logic
双版本同源逻辑：api/（Vercel Functions）与 cloud-functions/api/（EdgeOne Pages 云函数，Express 导出）
Payment
Stripe Checkout（test 模式）+ 微信/支付宝演示收银台；入账走 RPC mark_order_paid
Deploy
Zeabur Docker 多阶段构建（node:22 → node:22-slim），node server/zeabur.mjs 同托管 dist/ 与 /api，main 分支自动部署

解决什么问题Problem
给 MT5 交易者一个开箱即用的 AI 辅助层（连接 → 助手 → 分析 → 复盘）；同时给开发者一套订阅制 AI 产品的完整参考实现——落地页、Auth、定价、支付、合规文案一次配齐。An out-of-box AI layer for MT5 traders — and a complete subscription-product reference for builders.
什么场景，什么结果Scenario → Outcome
交易者：注册 → 连接 MT5 → AI 助手/分析/诊断/复盘，订阅解锁完整功能。开发者：clone + 环境变量 → 一套可上线的订阅付费产品骨架。Traders: sign up → connect MT5 → assistant/analysis/review. Builders: clone + env vars → a shippable paid-product skeleton.
什么结构Architecture
